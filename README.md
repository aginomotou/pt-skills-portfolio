# Loading...

The compiled portfolio of **Loading...** (Aguilar, Cortez, Cruz and Dival), BSIT - 301I, for **ITC C309-301I Presentation Skills for IT**.

- `index.html`: the landing page, introducing the group's portfolio
- `aguilar.html`, `cortez.html`, `cruz.html`, `dival.html`: one page per member, each split into Prelim, Midterm and Finals, and each term into Performance Tasks, Product and Reflection

**Members: read [GUIDE.md](GUIDE.md).** It shows where your PDFs go (`files/<your-name>/<term>/`) and where your links, YouTube videos and reflections go (`content/<your-name>.js`).

It is a static site with no build step, so it runs on GitHub Pages as it is (Settings → Pages → Deploy from branch → `main` / root).

The only pictures are the members' own photos (`files/<name>/photo.jpg`). Everything else is drawn in CSS and SVG.
